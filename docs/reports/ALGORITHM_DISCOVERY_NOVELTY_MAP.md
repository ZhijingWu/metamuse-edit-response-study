# Algorithm-discovery novelty map

**Conclusion:** generic adaptive feedback, workload co-evolution, semantic diversity, offspring potential and cheap-to-expensive evaluation are established. The narrow intersection retained for testing is **when a performance-based equivalence decision is unsafe for a particular future edit operator, and whether selective matched-edit probes can improve search after paying their cost**. Originality is unconfirmed; the local policy tests do not establish superiority.

Assessment: **20 October 2026**. This is a targeted primary-source challenge, not exhaustive novelty clearance. Paper-specific methods below were inspected in the named sections/official descriptions; competitor repositories were not generally reproduced.

| Primary work / inspected scope | Already established | Consequence for proposed mechanisms |
|---|---|---|
| [MetaMuse, ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/85632be2cd69e9a0ef4ba054c096fac9-Abstract-Conference.html), complete paper and both release surfaces | Performance feedback, GP stimulus selection, exploration/exploitation, structured generation, multiple workload families | Feedback-guided steering and history-aware generation are already solved components. Restoring the supplement's behavior in the current CLI is reproduction. |
| [FunSearch, Nature](https://pmc.ncbi.nlm.nih.gov/articles/PMC10794145/), program database and sampling sections | Islands, per-input score signatures, fitness-biased cluster sampling and shorter-program preference within clusters | It **retains multiple programs within a signature cluster**; do not claim it blindly deletes all performance duplicates. Selection/compression can still alter future proposal distributions. |
| [AlphaEvolve, arXiv 2506.13131v1](https://arxiv.org/html/2506.13131v1), §§2.2–2.6 | Evolving programs, evaluation feedback, MAP-Elites/island-inspired database and evaluation cascades | Program evolution, diverse archives, multi-metric scores and staged validation are covered. |
| [EoH, ICML 2024](https://proceedings.mlr.press/v235/liu24bs.html), official method description | Joint evolution of natural-language thoughts and executable code | Searching high-level ideas or combining thought/code changes is not new. |
| [ReEvo, NeurIPS 2024](https://papers.nips.cc/paper_files/paper/2024/hash/4ced59d480e07d290b6f29fc8798f195-Abstract-Conference.html), official method description | Reflective evolutionary improvement and verbal guidance | Failure reflection and ordinary mutation feedback are covered. A causal replay operator would require a technical distinction. |
| [ShinkaEvolve v1](https://arxiv.org/html/2509.19349v1), §§3, 5 | Performance/offspring-count parent sampling, code novelty rejection, adaptive model selection | Generic bandits, avoiding repeated code and balancing novelty/performance are covered. A replacement novelty filter must beat these ideas at matched token/evaluation cost. |
| [HiFo-Prompt v2](https://arxiv.org/html/2508.13333v2), §3 | Adaptive design guidance, reusable insights, utility and credit assignment | Adding a memory of useful hints or choosing mutation strategies from previous outcomes is covered. |
| [ASRO, ICML 2026](https://proceedings.mlr.press/v306/ke26b.html), §3 via [v2 full text](https://arxiv.org/html/2601.22896v2) | Program-level solver/generator co-evolution, payoff matrices, mixed strategies and adaptive curricula | “Evolve challenging workloads to improve generalization” is directly covered, including online bin packing. |
| [DHEvo](https://arxiv.org/abs/2507.15615), primary abstract; [Genet](https://www.microsoft.com/en-us/research/publication/genet/), official method description | Data/algorithm co-evolution; baseline-relative curriculum difficulty in Yan's own work | Generalization-driven workload selection cannot be presented as an unexplored MetaMuse intersection without a more specific algorithm. |
| [MAP-Elites](https://arxiv.org/abs/1504.04909), primary description; [SAIL](https://pubmed.ncbi.nlm.nih.gov/29883202/), primary abstract | Behavioral niches and high-quality diversity; surrogate-assisted economical illumination | A new descriptor plus an ordinary archive is a modest adaptation unless it yields a new principle, guarantee or demonstrated advantage. |
| [Quality Evolvability ES](https://arxiv.org/html/2103.10790v1), method sections | Selection for a high-quality, diverse **offspring distribution**, rather than current quality alone | The motivation for measuring descendants is not new. The proposed distinction concerns edit-conditioned representative equivalence, not invention of evolvability. |
| [Clade-AHD v1](https://arxiv.org/html/2602.00549v1), §§3.1–3.4 | Descendant-based Bayesian beliefs, Thompson sampling and clade freezing in LLM heuristic discovery | “Retain a weak parent because its descendants may be useful” is directly covered. Genealogical productivity must be a strong comparator, not ignored. |
| [Genetic programming with semantic equivalence classes](https://run.unl.pt/server/api/core/bitstreams/21747b94-066f-4441-beeb-891f6e26c3f5/content), §§1–3 | Semantic equivalence, class-level search and filtering already explored classes | Output equivalence and semantic filtering predate LLM discovery. Equal sampled performance is even weaker than full semantics. |
| [Semantic neutral drift](https://link.springer.com/article/10.1007/s11047-019-09772-4), primary abstract/method context | Fitness-preserving transformations can change reachable search regions | Neutral re-expression to improve evolvability is not a new general principle. Include cheap neutral drift before paying for probes. |
| [Mutation Without Variation v1](https://arxiv.org/html/2606.05408v1), §§1–3 | LLM mutation can converge structurally; study deliberately excludes task fitness/behavior | The residual empirical question is its interaction with executable quality and selection, not discovering that LLM mutations have structural bias. |
| [AFlow, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/5492ecbce4439401798dcd2c90be94cd-Abstract-Conference.html), primary method description | Execution-evaluated workflow search | Hierarchical workflow/operator search is not intrinsically novel. It is less close to the selected archive question than the evolution papers above. |

Bayesian optimization supplies uncertainty-aware acquisition; genetic programming supplies mutation/recombination and semantic operators; program synthesis/repair supplies counterexample refinement; test-time search supplies adaptive compute allocation. No claim is made that these general mechanisms become novel when placed inside MetaMuse. The classical condition for safe Markov-state aggregation also underlies the selected mathematical formulation; its coupling bound is borrowed reasoning, not a claimed new theorem.

## Classification of the focused opportunities

| Opportunity | Classification after challenge |
|---|---|
| GP/UCB/bandit stimulus selection, prompt memory, ordinary reflection | **Already established**; source-specific repairs are engineering |
| New workload generators, minimax/robust selection, specialized/general policies | **Already established at the broad level**; ASRO/Genet/DHEvo are direct threats |
| Structural/behavioral distance used as another diversity metric | **Similar prior methods**; insufficient by itself |
| Preserve same-performing representatives with distinct edit-conditioned transition behavior | **Technically distinguishable hypothesis**, with high novelty risk from semantic GP, neutral drift, evolvability and Clade-AHD |
| Probe only when an equivalence-based retention decision would otherwise lose a representative | **Potential systems/search-policy intersection**, not certified novel. The implemented local revision loses to cheap controls on mean held-out quality. |
| Matched-state counterexample replay followed by constrained branch mutation | **Unresolved intersection**, but not yet sufficiently distinguished from cost-to-go learning, semantic GP and counterexample repair; not selected |

The defensible claim is currently an executable counterexample study and two bounded mechanism tests. There is **no evidence of a state-of-the-art algorithm-discovery method**, and no basis for a “first use of structural novelty” claim. A stronger contribution would require showing that the exact edit-conditioned information changes useful discoveries beyond what cheap structural diversity, neutral drift and descendant-quality selection already achieve.
